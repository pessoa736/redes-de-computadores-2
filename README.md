# redes-de-computadores-2

esse repositorio foi feito para conseguir resolver, praticar, execitar e/ou relatar o conteudo dado nas aulas de Redes de Computadores 2 (RC2) ministrada pelo docente Vitor Saraiva Ramos na Escola de Ciência e Tecnologia (ECT) da Univesidade Federal Do Rio Grande do Norte (UFRN).

## como estar organizado o repositorio?

```txt
redes-de-computadores-2/    # root do repositorio.
    aulas/                  # onde fica guardado cada aula dada.
        aula-N/             # pasta onde esta o conteudo da aula.
            relatorio.md    # relatorio.
            ...             # arquivos necessarios para o andamento da aula.
    README.md               # documento de explicação do repositorio.
    ...                     # talvez mais coisas

```
